Medium Paste Compatibility Checker

① "Copy" copies the original HTML with formatting → ② Paste into Medium → ③ Paste the result back here and it's auto-graded OK / Broken.

How to use

  1. Click "Copy" on a card to copy it as rich HTML
  2. Paste it into the Medium editor (Cmd/Ctrl+V)
  3. Check how it renders in Medium, then select that content and copy it again
  4. Click the "Paste result from Medium" box on this tool and paste (Cmd/Ctrl+V)
  5. The structure is analyzed automatically and graded OK / Broken / Partial, with a badge and a reason
  6. If the auto-grade looks wrong you can override it with the dropdown. When you're done, "Export results" writes everything out as Markdown
* Grading is a simple heuristic that inspects the HTML structure (tags, nesting, attributes) captured at paste time. A visual double-check is recommended.
* Important note: Medium sometimes expresses appearance through its own CSS classes rather than inline styles. When that happens, content can look perfectly fine inside Medium's editor, but look like plain unstyled text once copied back out, because the class names have no matching stylesheet outside Medium. That's a different question from "how does it look once pasted into Medium" — it's about "what survives copying it back out of Medium." When a "Partial" verdict shows a class name, that's this case — trust what you actually saw in the Medium editor over this tool's verdict.
